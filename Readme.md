## 🚀 Adding a New Writeup

All writeups live in `_posts/` with the filename convention `YYYY-MM-DD-<title>.md`.

To add a new writeup, create a file in `_posts/`:

```markdown
---
title: "TryHackMe - BoxName"
date: 2025-09-17 12:00:00 +0000
categories: ["CTF", "TryHackMe"]
tags: ["linux", "privesc", "sqli"]
---

Your writeup content here...
```

Once pushed to `main`, GitHub Actions will automatically build and publish the changes to [cy3erdr4g0n.github.io](https://cy3erdr4g0n.github.io).
